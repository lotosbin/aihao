| 段位 | 材质 | 主色 | 辅色 | 特效 | 段位名称前缀 | 徽章渐变 |

| 进阶级 | 银 | `#C0C0C0` | `#808080` | 拉丝 | 白银 | `#C0C0C0 → #808080` |
| 封师级 | 金 | `#FFD700` | `#DAA520` | 抛光 | 黄金 | `#FFD700 → #DAA520` |
| 大师级 | 铂金 | `#E5E4E2` | `#A9A9A9` | 镜面 | 铂金 | `#E5E4E2 → #A9A9A9` |
| 封神级 | 紫钻 | `#9400D3` | `#4B0082` | 星光 | 紫钻 | `#9400D3 → #4B0082` |
| 大神级 | 炫彩 | 渐变 | 多色 | 流光 | 炫彩 | `#FF0080 → #FFD400 → #00E5FF → #7C4DFF → #00E676` |

**设计决策**

1. **段位名称前缀**：原文 5.3 示例用了「黄金」，而 5.2 的材质名是「金」。为与「铂金 / 紫钻 / 炫彩」保持两字对齐，前三级统一取前缀 **青铜 / 白银 / 黄金**。
2. **炫彩渐变**：原文只写「渐变 / 多色」，此处固定 5 个停靠色，保证六端渲染一致；主色/辅色仅作为渐变的起止锚点。
3. **文字颜色**：浅色材质（银、金、铂金）用深色字，深色材质（铜、紫钻、炫彩）用浅色字，按主色亮度自动反转，避免徽章文字看不清。
4. 颜色在 `core` 中一律以 `#RRGGBB` 字符串保存，`core` 不依赖任何 UI 框架；各端渲染时再转成平台颜色对象（见 `app/shared/src/ui/BadgePalette.kt`）。

## 2. 段位名称生成规则（规格 5.3）

### 2.1 模板

```
[材质前缀] + [最高层级爱好] + [身份后缀]
```

### 2.2 身份后缀库

| 版本 | 后缀库 | 实际拼接写法 |
| :--- | :--- | :--- |
| 男性版 | 佬、师、匠、侠、宗、王 | 佬 / 师 / 匠 / 侠 / **宗师** / **之王** |
| 女性版 | 师、女王、达人、仙女、生活家、觉醒者 | 师 / 女王 / 达人 / 仙女 / 生活家 / 觉醒者 |

「宗」写成「宗师」、「王」写成「之王」是为了组合顺口（紫钻太极宗师、炫彩公园之王）。部分爱好名称本身已构成身份，则不缀后缀（铂金木工、炫彩佛系养生）。

### 2.3 生成算法

1. 取用户全部爱好中**段位最高**的一层作为「最高层级」。
2. 该层有多个爱好时：优先选自带身份后缀的条目；仍并列则取传入顺序的第一个。结果只取决于输入顺序，保证可复现。
3. 材质前缀取该段位对应材质。
4. 后缀取爱好自带后缀；若该后缀不属于当前版本后缀库（例如限定爱好「搓澡」只配了男性版后缀「佬」，却被女性版用户选中），回退为该版本首选后缀（男性版「佬」、女性版「师」），得到「青铜搓澡师」。

> 另有 `rankAlias` 机制：爱好在段位名称中可使用替代名称，例如「公园晨练」只取「公园」，从而得到规格示例中的「炫彩公园之王」。

### 2.4 示例对照（含一处口径冲突）

| 规格 5.3 示例 | 本库生成 | 说明 |
| :--- | :--- | :--- |

## 8. 内容审核与更新流程（规格 8）

### 8.1 审核标准

原文条款：不涉及政治、宗教、色情、暴力；不贬低任何性别、职业、地域；文案以自嘲、幽默为主，避免冒犯。

其中可自动化的部分已固化为 `core/src/content/ContentAudit.kt`，随 CI 执行：

| 规则 | 检查内容 |
| :--- | :--- |
| 段位爱好数量 | 每个版本每个段位必须有 6-7 个爱好 |
| 爱好 id 唯一 | 主力与限定内容之间不允许 id 重复 |
| 身份后缀归属 | 带版本的爱好，其后缀必须属于该版本后缀库 |
| 贬低性用词 | 名称、评语、标签说明、彩蛋奖励命中黑名单即拦下 |
| 限定内容可见性 | 节日限定必须有 `windowLabel` 或 `window`，用户要能看到生效时间 |
| 段位名称长度 | 超过 12 字会折行，提示精简或设置 `rankAlias` |

人工审核仍需覆盖政治、宗教、色情、暴力等语义判断，以及黑名单之外的冒犯性表达。

### 8.2 更新频率

- **常规更新**：每季度新增 2-3 个爱好。
- **节日更新**：提前 1 周上线限定爱好。
- **紧急更新**：根据用户反馈，48 小时内下架争议内容。

下架操作只需移除或改写 `core/src/content` 中的对应条目：限定内容与主力矩阵分离，删除限定条目不影响段位体系与其他内容。

### 8.3 用户共创

- 开放「提名新爱好」入口，用户可提交建议。
- 每月评选「最佳提名」，被采纳者获得限定徽章（对应彩蛋「共创者」）与隐藏标签「提名官」。
- 提名通过审核后追加到主力矩阵或限定内容，并同步更新本文档。
